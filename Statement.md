ACADEMIC PERFORMANCE PREDICTION SYSTEM


1. Problem Statement
Students academic performance depends on various factors such as Attendance, Study hours, Previous examination marks, Assignment completion, and Internal assessment marks. However, it can be difficult to identify early whether a student is performing well or needs improvement.
The Academic Performance Prediction System aims to develop a simple Python-based system that analyzes these factors and calculates a performance score. Based on the score, the system predicts the student's performance level and provides basic suggestions for improvement.

2. Scope of the Project
The scope of this project includes:
➣Collecting basic academic information from students.
➣Analyzing attendance, study hours, previous marks, assignments, and     internal marks.
➣Calculating an overall performance score using predefined weights.
➣Classifying students into different performance levels.
➣Providing personalized suggestions for improvement.
➣Demonstrating how Python can be used to solve a real-world academic problem without machine learning.
➣The project can later be extended with a database, graphical user interface, web application, or student performance history.

3. Target Users
The main target users are:
Students – To understand their current academic performance and areas needing improvement.
Teachers/Faculty – To get a simple overview of students' performance.
Academic Institutions – To support basic academic monitoring.
Parents/Guardians – To understand a student's general academic progress.
4. High-Level Features
➣Student Data Input:-
Allows users to enter attendance, study hours, previous marks, assignment completion, and internal marks.
➣Performance Score Calculation:-
Calculates an overall academic performance score using predefined weights.
➣Performance Prediction:-
Classifies performance as:
Excellent
Good
Average
Needs Improvement
➣Personalized Suggestions:-
Provides suggestions based on areas where the student has a lower score.
➣Simple and User-Friendly Interface:-
Uses a straightforward command-line interface that is easy for beginners to understand.
